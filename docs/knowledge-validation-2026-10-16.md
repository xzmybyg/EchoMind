# 本地面试题知识库验收（2026-10-16）

## 实现与边界

SQLite 保存提取后的文档文字快照、来源定位、手动问答、标签、FTS5 索引和向量；不修改导入源文件。数据位于 `%LOCALAPPDATA%\EchoMind\knowledge\knowledge.db`，模型位于独立组件缓存，应用升级不覆盖两者。备份前关闭应用，复制整个 knowledge 目录，不能只复制运行中的数据库而忽略 WAL。

支持 UTF-8/GB18030 TXT、Markdown、DOCX 段落与表格、文字型 PDF。导入先在本地预览，确认才写入；无正文的扫描件提示 OCR，旧 DOC 提示转换。来源定位为 PDF 页码或文档段落/行号，手动修订的正文不再冒充原页码。单文件限制 50 MB，PDF 限 500 页，提取文字限 200 万字。只保存文字，不复制原始二进制文件。

切分采用同一固定版本 BGE 分词器，含标题的片段不超过 384 token，相邻片段重叠最多 64 token。检索是 FTS5 trigram 与 512 维 CPU 向量的混合检索，每路前 20 条，倒数排名融合后去重，最多给回答接口 3 段。短技术词可匹配标题、别名、标签；相似度不是正确概率，不复用 Jev 阈值。

知识库增强默认关闭，用户主动启用且使用在线回答模式后，相关片段才随问题发送给回答模型；不上传全部文件、索引或本地路径。查询超时一秒/数据库不可用时继续普通回答；已取消或过期问题的检索结果不能覆盖新问题。导入、编辑、检索和建索引均不占 Tk 绘制线程。

## 实测检索模型与校准

- 模型：BAAI/bge-small-zh-v1.5，Qdrant ONNX 发布，CPUExecutionProvider，2 个计算线程。
- 固定修订：`46fbe35fd4374a00fee7de77dfddaeb6dd6a2c59`。
- 权重 SHA-256：`1294ea4b6331115a353d81f96b85e8c8d7fdcc284453d5b2fab5b016230aad38`。
- 已实际下载固定的 5 个模型文件并校验 SHA-256；未请求回答 API、未使用个人题库或录音。
- 可重复执行：`.venv/Scripts/python.exe scripts/evaluate-knowledge.py --model .runtime/knowledge-components/models/bge-small-zh-v1.5`。

固定语料 `scripts/knowledge-corpus.json` 包含 20 个技术主题、80 条库内问题/同义表述、20 条库外问题。使用真实模型遍历阈值；关键词命中可佐证稍弱的语义匹配，语义拒收阈值取 0.44（有词法佐证时下调 0.05），完整标题/明确别名匹配优先。

| 指标 | 校准集结果 |
| --- | --- |
| 前三条命中目标主题 | 75/80，93.75% |
| 库外问题误注入 | 1/20，5% |
| 一万片段热检索 P50 | 42.71 ms |
| 一万片段热检索 P95 | 49.24 ms |

准确率是校准集结果，不是独立留出集准确率，也不能保证对任意题库泛化。性能用 20 个实际片段及向量扩充到一万行，同时建立全部行的 FTS 索引，测试本机混合检索开销（30 次查询），并不代表测试了一万个独立技术主题；不含模型冷加载、文档导入和云端回答耗时。后续更换模型/修订时需要重新校准，不应直接复用阈值。

RAG 可以改善回答依据，但错误资料、相似却不同的问题、恶意文档指令仍需防范；系统将资料置于用户数据而非系统指令，且限制来源编号，但这不是完全消除生成幻觉的保证。资料不会被当作候选人个人经历。首版不含网页爬取、扫描 PDF OCR、简历管理或本地回答大模型。

## 回归与打包验证

完整回归 719 项通过（包括 unittest 子用例），覆盖原有录音采集、字幕、截图、流式接口、快捷键、窗口跟随，以及知识库导入预览、增删改查、重复导入、取消保留旧资料、数据库忙、损坏文档、模型缺失、下载校验和快速换题。界面测试在独立非交互测试桌面执行，验证 100% / 125% / 150% 缩放下管理窗口按钮可见、确认导入前数据库不写入。未调用真实在线回答接口、未采集用户麦克风。

轻量包依赖隔离验证通过：从打包的代码归档和运行库加载真实 CPU 检索模型、SQLite 检索、DOCX 模板及 PDF 组件，不借用开发环境 site-packages。打包主窗口在测试桌面成功启动并正常关闭。正式使用仍需用户通过组件管理下载检索权重；打包目录不含权重、用户资料或配置密钥。

回答区仅折叠显示本次真实检索来源；当前运行的问题记录保留片段快照，源文件删除后仍可回看。沿用现有问题记录生命周期，退出应用后清空记录，不额外持久化对话。知识库数据库与固定组件缓存独立于安装目录，升级不删除；模型下载完成后可在知识库手动重建语义索引。模型首字计时不包含本地检索耗时，检索耗时独立展示。
