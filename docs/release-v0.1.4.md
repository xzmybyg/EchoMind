## EchoMind v0.1.4 · 本地知识库与桌面稳定性改进

### 本次更新

- 新增本地面试题知识库：支持 Markdown、TXT、DOCX、文字型 PDF 的预览导入，以及手动问答、同义问法、标签、编辑、删除和搜索。不修改用户原始文档。
- 新增 CPU 语义检索组件 BGE-small-zh-v1.5（约 91 MiB），固定版本并校验 SHA-256；未下载时保留关键词检索，不占用语音识别 GPU。
- 可选 RAG 增强：确认问题后本地检索，最多将三个相关片段随问题发给现有回答接口，保留流式输出、可展开的参考来源和本次运行的问题记录快照。默认关闭；未命中、超时或失败时继续普通回答。
- 统一暖白工作台样式，优化按钮、侧栏和弹窗；弹窗相对主窗口居中，支持多屏负坐标。
- 修复会议来源切换和采集启动时沿用空列表、旧 PID 的问题；自动重新查询并选择腾讯会议主进程，查找期间可停止取消，超时后可重试。
- 改进刷新线程与窗口变量回调的生命周期清理，增加不含密钥和会议内容的本地致命故障堆栈日志。

### 首次安装与升级

首次安装下载 **EchoMind-v0.1.4-windows-x64.zip**，解压整个 EchoMind 文件夹后运行 **EchoMind.exe**。不要单独复制 EXE，也不要把更新 ZIP 当作首次安装包。

已有支持更新功能的版本可选择“设置 → 检查更新 → 立即更新”。**EchoMind-update.zip** 专用于一键更新。配置、已下载语音/GPU 组件和 `%LOCALAPPDATA%\EchoMind\knowledge` 中的题库保留，不需要因为升级重新下载完整组件。旧版本 Release 的语音组件仍被复用，不应删除。

主程序不捆绑检索权重、语音权重、Qwen 独立 GPU 环境或用户资料。已有本地组件继续复用；腾讯云语音和在线回答仍需用户自行配置服务凭据，可能产生费用。

### 知识库使用

左侧“知识库”导入文档或新增问答；“检索模型”中主动下载 CPU 模型，然后重建语义索引。勾选“启用知识库增强回答”并重新开始采集后生效。

本地检索不上传整份文档、完整题库或本地路径，只向在线回答接口发送命中的少量片段。仅字幕和离线演练不触发在线知识库回答。扫描 PDF 暂不自动 OCR，旧 DOC 请先转为 DOCX。问题记录及来源快照仍只保留在当前运行中，退出后清空；知识库资料持久保存在本机。

### 验证与已知边界

732 项回归通过。打包运行库验证了真实腾讯会议进程的连续刷新与主进程自动选择、刷新中关闭窗口及无音频的采集启动分发；主 EXE 在隐藏测试桌面等待刷新后正常关闭。

真实 BGE 模型在固定校准集上前三条召回命中 75/80（93.75%），库外问题误注入 1/20（5%）；一万条重复扩充的模拟索引热检索 P95 约 49 ms。结果不代表任意题库的泛化准确率或所有机器的性能。知识库改善回答依据，不直接提高语音识别准确率，也不能保证消除生成幻觉。

已对进程刷新和 Tk 对象释放做针对性修复，但此前 Windows 日志中的相同原生闪退尚未稳定复现，不能保证覆盖其所有成因。若仍退出，可结合 `%LOCALAPPDATA%\EchoMind\logs\native-crash.log` 继续定位。该日志只记录启动信息与致命堆栈，不记录密钥、音频或回答，也不自动上传。

程序未进行代码签名。HTTPS 与 SHA-256 用于传输及完整性校验，不替代代码签名。
