# 腾讯云实时识别接入（试用）

桌面程序的“运行设置 → 语音 → 识别引擎”可选择“腾讯云（在线 / 上传音频）”。默认仍为本地 Whisper；保存配置后保留所选引擎。没有真实账号调用结果前，不承诺准确率或延迟优于本地模型。

## 配置与使用

本次试用构建：`dist/light-v0.1.3-tencent-asr/EchoMind/EchoMind.exe`。请保留整个 EchoMind 文件夹，先退出旧版再启动。源码开发环境安装 `services/transcription` 的项目依赖后运行即可，新增依赖为 `websockets>=15,<16`。

1. 在[腾讯云语音识别控制台](https://console.cloud.tencent.com/asr)开通服务，确认资源包或后付费设置。中英大模型与通用模型计费不同，以控制台当前价格为准。
2. 在[访问管理](https://console.cloud.tencent.com/cam/capi)准备 AppID、SecretId、SecretKey。建议使用仅有语音识别权限的子账号凭证；不要把凭证发到聊天、截图、日志或 Git 仓库。
3. 选择腾讯云引擎，在语音页填写以上三项。默认 `16k_zh_en`（中英大模型）；也可选 `16k_zh`（中文通用）对照。与 DeepSeek / Jev 密钥分开。
4. 点击“保存配置（含加密密钥）”。SecretId、SecretKey 使用 Windows DPAPI 保存到 `%LOCALAPPDATA%\EchoMind\settings.json`，仅原 Windows 用户可解密。AppID 和模型名称不是密钥，普通保存。旧配置仍可读取。
5. 每次启动应用或切换识别引擎后，需重新勾选“同意上传音频到腾讯云”。这个确认不保存。会议采集仍需参与者授权。
6. 输入来源先选“本机麦克风”，回答方式先选“仅字幕”，点击“开始测试”。注意：仅字幕只是不调用回答模型，腾讯云识别仍上传音频并可能计费。
7. 确认字幕正常后再启用在线回答，或将来源切换为腾讯会议。停止后才能切换识别引擎。

云端模式不需要本地 ASR 模型、GPU 或 VAD 组件。新安装首次打开若仍选默认 Whisper，可能弹出本地组件窗口，可关闭后切换腾讯云；已保存腾讯云设置时不会自动要求下载。识别设备 GPU/CPU 的选择对腾讯云无效。

## 行为与限制

- 只访问固定的腾讯云 ASR WSS 地址；音频格式为 16 kHz、单声道、16 位 PCM，每 200 ms 一包，按实时速率发送。不会保存录音。
- 收到临时结果立即更新字幕；收到稳定结果提交现有问题判断链路。同一段最终字幕去重；字幕仍统一转为简体。云端断句设为 1000 ms，下游保留已有跨停顿问题拼接逻辑。
- 现有技术热词按逗号、空白拆分，去重并以权重 5 发送，不使用强制同音替换。默认前端术语仅适合前端问题；通用会话可选“通用”清空热词。留空不传临时热词，腾讯云控制台配置的默认热词表仍可能生效。
- 停止后不再上传缓冲音频，发送结束标记，最多等待 3 秒收取尾句，再关闭连接；因此尚未发送的不足 200 ms 尾音可能被舍弃。停止后尾句只显示字幕，不触发新回答。
- 网络异常、鉴权失败、欠费等会停止会话并给出安全提示。不静默重连，不自动切换到本地引擎。手动停止、检查配置后重新开始。
- 网络建立和握手各最多等待 5 秒；字幕耗时包含云端断句及传输，不等于纯模型推理时间，也不代表回答首字耗时。
- 云端返回的错误正文、签名 URL、密钥和音频不写日志。发行程序不包含任何用户凭证。批量分发应用时，不要把开发者长期密钥内置给其他人，应由用户自行配置或使用后端授权方案。

## 验证边界

自动测试使用假凭证和模拟回复；另有本机 WebSocket 服务器测试实际库的发送、临时字幕、最终字幕和结束流程。覆盖签名、编码、节流、去重、简体、异常输出、错误脱敏、连接清理、配置加密、界面切换及不下载本地组件。

目前没有调用真实腾讯云服务、没有上传用户音频或产生识别费用。还需要用户本机配置有效凭证后验证账号权限、区域/网络可达性、计费、识别效果与实际延迟。

2026-10-11 本地完整回归：595 项测试通过，包含真实本机 WebSocket 收发测试；这不等于真实腾讯云账号联调通过。

建议复测：React Hooks / Fiber、中英混合句、句中停顿 1–2 秒、十秒静音、背景噪声。使用相同设备与同一段音频对比本地和云端，不根据单句结果直接切换默认方案。

官方协议：[实时语音识别 WebSocket](https://cloud.tencent.com/document/product/1093/48982)。本次仅提供桌面接入；命令行原来的本地识别参数不变。
